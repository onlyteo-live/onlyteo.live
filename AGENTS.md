# onlyteo.live web page

## Overview
Simple web page that acts as a public profile for the onlyteo persona.
It contains a small bio and links to social media, code repositories and public web pages. 

## Layout
The web page has a layout and styling that is made to look like a Gnome/KDE Linux terminal.

## Technology
The web page is a static html pages with some basic JQuery logic, Bootstrap stryling and FontAwesome icons.
It is bundled using Vite and deployed to GitHub Pages using GitHub Actions.
